# GPT-5.6 Sol control source

The control group uses the official model slug `gpt-5.6-sol` with the `high`,
`xhigh`, and `max` reasoning effort levels through both Codex and Pi. OpenAI's model
documentation lists GPT-5.6 Sol as a Responses model with image input support
and `high`/`xhigh`/`max` reasoning effort. The local Pi 0.84.1 model inventory resolves
the same slug through its `openai-codex` provider.

Source: [OpenAI GPT-5.6 Sol model](https://developers.openai.com/api/docs/models/gpt-5.6-sol)
